# 🌤️ My Project for Web Development: AI-Assisted Weather Web App

Isang dynamic at full-stack web application na binuo gamit ang Python backend upang kumuha at magpakita ng real-time na impormasyon tungkol sa panahon (weather data) gamit ang isang external Weather API.

## 🚀 Live Demo
👉 https://my-project-for-web-development-1.onrender.com/
*(May nakita akong +11 deployments sa iyong GitHub sidebar sa kanan, kunin mo ang active link doon at ilagay dito)*

## 💡 Paano Ko Ito Ginawa (AI Collaboration & Logic)
Ang proyektong ito ay nagpakita ng aking pag-unlad sa backend development at API integration sa tulong ng Claude AI:
- Ginamit ko ang **Claude AI** bilang katuwang sa pagbuo ng disenyo at pagsusuri kung tugma ba ang UI sa aking vision.
- Manu-mano kong binasa at pinag-aralan ang **JavaScript** sa frontend at **Python** sa backend upang masigurong tama ang pagbato ng data mula sa Weather API patungo sa interface ng app.

## ✨ Mga Tampok (Features)
- **Live Weather Data Fetching:** Kumukuha ng totoong impormasyon sa panahon gamit ang isang external Weather API request sa pamamagitan ng Python.
- **Robust Python Backend:** Pinapatakbo ng malinis na server-side routing gamit ang Python (`app.py`).
- **CORS Enabled:** Naka-configure gamit ang `flask-cors` sa `requirements.txt` para sa ligtas at maayos na cross-origin requests sa pagitan ng frontend at backend.
- **Render Ready:** May kasamang `render.yaml` file para sa mabilisang automated deployment sa cloud.

## 🛠️ Tech Stack
- **Backend:** Python (Flask, Flask-CORS)
- **Frontend:** HTML5, CSS3, JavaScript (Web APIs)
- **Deployment:** Render / Vercel

## 📁 Estruktura ng Repository
- `app.py` - Pangunahing Python backend na nagpoproseso ng Weather API calls at data management.
- `js/app.js` - Client-side script na nagpapagana ng user interactions at nagpapakita ng weather results.
- `css/` - Direksyon na naglalaman ng mga custom styles para sa user interface.
- `render.yaml` - Configuration file para sa maayos na hosting at deployment sa Render platform.
